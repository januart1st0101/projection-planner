# 計算、輸入與限制

公式：T=D/W；D=T×W；W=D/T；H=W÷(比例寬/比例高)；對角線 hypot(W,H)；英吋=公尺/0.0254；像素間距=W/水平像素×1000 mm。內部 m，輸出圖尺寸 m、像素間距 mm。原生解析度假定方形像素，因此水平及垂直間距相同。

JSON 欄位：

- 必填 metadata：`project`、`version`、`date`（YYYY-MM-DD）。控制字元拒絕。
- 必填 `resolution`：`Full HD`、`WUXGA`、`4K UHD` 或 `[1920,1080]`。自訂像素須正整數，布林不算整數。
- `aspect`：`16:9`、`16:10`、`4:3` 或自訂 `寬:高`；省略則由解析度推導。若與原生像素比例不一致，報錯。這是原生畫面矩形，不是另一塊任意比例的實體幕布。
- `width`、`height`、`distance`、`position`：文字加單位，例如 `6m`、`600cm`、`6000毫米`；不接受未標單位。height 為額外檢查，不能取代主要輸入；position 為候選鏡頭位置，用於只有 width+lens 時的檢查，與 distance 同時提供必須相等。
- `throw_ratio` 正數、`lens: [最小T, 最大T]` 可相等，不可倒置。
- 求解最少兩個 W、D、T；若只給 W+lens，列 D 區間且不選定位置。圖中 D 用 position 或最小 D 示意並標記。position 不是主要求解欄位。
- `content_aspect` 與 `fit`：預設 contain，cover/stretch 僅依明確指示；未提供內容比例視為原生比例。
- `geometry` 只接受 `standard`；`notes` 是文字陣列。

一致性：多給的 W/D/T、高度、比例及位置都檢查；浮點相對容差 1e-6、絕對容差 1e-9 m（純數值驗算，不是光學施工精度）。零、負值、NaN/Infinity、未知欄位、無效日期、非法單位、未支援的幾何皆拒絕。為避免極端與特殊光學誤用，本版比例寬/高限制 0.1–10，投射比限制 0.4–10；這是本工具的保守適用界線，不是投影機的物理定律。界線內仍須確認是否一般正投，不能據 T 值推斷光學類型。

鏡頭範圍：[Tmin×W,Tmax×W]。候選位置在閉區間內才通過；區間外是可計算但不可達成的警告，非矛盾 JSON 錯誤。距離是依原廠鏡頭光學參考點至幕面，未提供定義時不把機身前緣、鏡頭中心符號或吊架當成精確量測點。原廠允許的距離／對焦範圍可能比投射比幾何區間更窄，本版不臆測它。

等比適配：內容比例 Cr≥原生比例 Ar 時有效內容 W×(W/Cr)，上下每側黑邊 (H−W/Cr)/2；反之有效內容 (H×Cr)×H，左右黑邊 (W−H×Cr)/2。cover 選足以蓋滿的內容矩形，列超出幕面的左右／上下每側裁切量；stretch 以幕面全幅顯示並警告變形。未計整數像素取整或播放設備行為。

像素間距指原生全幅，不因影片黑邊改變；本版不計有效內容像素數。輸出四位小數顯示、計算及 JSON 保留浮點。大／小數使用科學記號。
