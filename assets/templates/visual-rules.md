# PP-1.0 固定圖面規範

畫布 1600×1000 SVG px、外邊距40。標題 y20–120，俯視框 (40,145,920,655)，正視框 (980,145,580,305)，規格框 (980,465,580,335)，底框 (40,820,1520,160)。版型版本獨立於專案版本；更新專案數值不得改區塊。

字體依序 Noto Sans CJK TC / PingFang TC / Microsoft JhengHei / sans-serif。圖上文字仍可編輯；沒有中文字體的環境應安裝合法 CJK 字體後渲染，不捆綁第三方字型。標題26、區標20、內文15–18、註解14–16；底部固定19px行距。底色 #f5f7fa，主色 #236b8e、尺寸線 #42657d、警告 #b44b38。幾何線／尺寸線2px；雙向三角尺寸箭頭；圖形局部比例尺 px/m 隨輸入計算。

俯視投射三角形 D 和 W 用同一比例尺 min(570/D,390/W)。鏡頭中心固定(175,435)，機身是符號而非實測。D 尺寸線固定y700、W 尺寸線於幕右34px。正視矩形以 min(360/W,150/H) 等比置中；各視圖尺度不同且各自明列，不允許不註記地拉伸。

長文字按 Unicode 全形2／半形1個單位換行；標題每行70單位最多2行，版本42單位最多1行；日期與單位各自固定一行，不能被長版本名擠掉；超出末行加…，Markdown 保留全文。所有內容有固定 clipPath 作最終界限。底部最多5行（每行146單位），超出時最後一行固定提示「完整限制見 Markdown」。規格值為有界長度的數值；超長專案／備註不參與幾何排版。

相同正規化 JSON（含明確日期）輸出 byte-identical SVG。像素渲染因平台字體可不同；同一 renderer/font 可重現。此版只承諾圖形區內的等比，不承諾跨專案相同比例尺。參考完整範本：`examples/A.svg`。
